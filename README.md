## Brief Project Description
The Hotel Booking System is a web-based application designed to simplify hotel operations by managing room information, customer bookings, check-in/check-out processes, payments, and reservation records. The system enables hotel staff to efficiently manage reservations while allowing customers to browse available rooms and make bookings through a centralized platform.
